# Sample course export

`fictional-course-export.imscc` is a small, entirely fictional Canvas course export ("Introductory Biology (sample)", BIO 101) for trying course export import offline. Sign in as an instructor, open **Import courses**, and upload it.

It deliberately contains issues TeachWell's checks find: file-name and missing image alt text, vague link text, a skipped heading level, an assignment without a due date or rubric, an unpublished page and module, and a module named outside the course's "Week N" pattern. It also includes a quiz and a discussion, which are listed as not imported.

It follows Canvas's export layout but was written by hand, so it is not proof that every real Canvas export imports correctly.
